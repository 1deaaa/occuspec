# ADR-01 规则引擎下限、Agent 自主编排

- 状态：已接受（原为"规则引擎为主、模型为辅"，随 Agent 化改造修订）
- 背景：判定结论必须可复现、可审计，且逐条引用标准原文；纯模型输出不稳定，无证据链。
  但把检索流程写死又会限制模型对多标准、多阶段的综合判断能力——
  实测模型能自主跨标准取证并把结论从"职业禁忌证"上调到"疑似职业病"。
- 决策：
  1. 判定由 Agent 自主编排：模型自行决定调用哪些检索工具、用什么元数据过滤维度、查几轮，
     最后通过终止工具 `record_conclusion` 提交结构化结论与依据。
  2. 规则引擎结论作为**不可下调的下限**（`rule/ConclusionPolicy`）：
     模型可上调结论（发现更多风险），不得下调；被拦截时记录来源 `RULE_FLOOR`。
  3. 判定链路全量留痕：轮次、工具调用序列、推理摘要、模型提交的依据写入 `assessments`。
- 后果：
  - 模型故障或未提交结论时回退规则结论（来源 `RULE_FALLBACK`），接口不抛穿；
  - 结论来源可区分（`AGENT`/`RULE_FLOOR`/`RULE_FALLBACK`），便于复核时判断可信度；
  - 代价是单次判定耗时随检索轮次增长（实测 3–8 分钟），生产建议走 SSE 流式并按下调
    `reasoning-effort`。
