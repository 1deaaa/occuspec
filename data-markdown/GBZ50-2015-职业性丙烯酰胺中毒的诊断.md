# 前 言 

> <sup>根据《中华人民共和国职业病防治法》制定本标准。</sup> 

本标准按照 GB/T1.1<sup>—</sup> 2009<sup>给出的规则起草。</sup> 

本标准的第5章为推荐性的,其余为强制性的。 

本标准代替 GBZ50—2002《职业性慢性丙烯酰胺中毒诊断标准》。 

与 GBZ50—2002相比,主要修改内容如下: 

———增加了急性丙烯酰胺中毒的诊断原则、诊断分级和处理原则,并将标准名称改为职业性丙烯酰 胺中毒的诊断; 

———删除了慢性中毒的观察对象; 

- ———在慢性中毒的分级中增加了肌力和神经-肌电图检查的内容,删除了重度分级中明显嗜睡及小 脑功能障碍的内容; 

———神经-肌电图的检查方法及其结果判断基准参见标准由 GBZ76修改为 GBZ/T247。 

本标准负责起草单位:北京大学第三医院。

# 职业性丙烯酰胺中毒的诊断 

## 1<sup>范围</sup> 

本标准规定了职业性急性和慢性丙烯酰胺中毒的诊断原则、诊断分级及处理原则。

## 3<sup>诊断原则</sup> 

## 3.1<sup>急性中毒</sup> 

根据短期内接触大量丙烯酰胺的职业史,以中枢神经系统功能障碍为主的临床表现,结合实验室检 查结果及工作场所职业卫生学调查,进行综合分析,排除其他类似疾病后,方可诊断。 

## 3.2<sup>慢性中毒</sup> 

根据长期接触丙烯酰胺的职业史,出现多发性周围神经损害的症状、体征及神经-肌电图改变,结合 工作场所职业卫生学调查,排除其他病因引起的周围神经疾病后,方可诊断。 

## 4<sup>诊断分级</sup> 

## 4.1<sup>急性中毒</sup> 

## 4.1.1<sup>轻度中毒</sup> 

短期接触大量丙烯酰胺后,出现头痛、头晕、乏力,接触局部皮肤多汗、湿冷、红斑、脱皮,或伴四肢麻 木并同时具有下列表现之一者: 

a<sup>)轻度意识障碍(见</sup> GBZ76<sup>);</sup> 

b<sup>)小脑性共济失调如持物不稳、站立不稳或步态蹒跚。</sup> 

4.1.2<sup>重度中毒</sup> 

在轻度中毒表现基础上,具有下列表现之一者:

长期接触丙烯酰胺,局部皮肤出现多汗、湿冷、脱皮、红斑或肢端麻木、刺痛、下肢乏力等症状,同时 具有下列表现之一者:

- c<sup>)深感觉明显障碍伴感觉性共济失调;</sup>

# 4.2.3<sup>重度中毒</sup> 

在中度中毒基础上,具有下列表现之一者: 

- a<sup>)肢体肌力减退至</sup> 2<sup>级及以下;</sup> 

- b<sup>)四肢远端明显肌肉萎缩;</sup> 

- c<sup>)神经</sup> -<sup>肌电图检查提示严重周围神经损害(见</sup> GBZ<sup>/</sup> T247<sup>)。</sup> 

# 5<sup>处理原则</sup> 

# 5.1<sup>治疗原则</sup> 

5.1.1<sup>急性中毒者应立即脱离丙烯酰胺作业环境,脱去污染的衣物,清洗污染的皮肤、黏膜,并采用吸</sup> 氧、改善微循环、神经营养药物治疗,如有明显意识障碍者可短期使用糖皮质激素治疗。 5.1.2<sup>慢性中毒可用</sup> B<sup>族维生素、神经营养药物及中医中药,并辅以康复治疗及对症治疗。</sup> 

5.2<sup>其他处理</sup> 

- 5.2.1<sup>急性中毒者如有后遗症参照</sup> GBZ<sup>/</sup> T228<sup>处理。</sup> 5.2.2<sup>如需劳动能力鉴定,按</sup> GB<sup>/</sup> T16180<sup>处理。</sup>

# 附 录 A (资料性附录) 

# 正确使用本标准的说明 

A.1<sup>丙烯酰胺有晶体和水溶液两种形态,工业生产中主要使用丙烯酰胺水溶液。在污水处理、石油开</sup> 采、造纸、纺织、印染等行业及生产聚丙烯酰胺、合成丙烯酰胺、N,N-亚甲基双丙烯酰胺、N-羟甲基丙烯 酰胺等工艺过程中均可能发生中毒。 A.2<sup>经皮肤吸收是职业性丙烯酰胺中毒的主要途径,因此,在病因分析和中毒程度判定时,要充分考虑</sup> 皮肤污染的程度。 

A.3<sup>在急性中毒恢复期可出现周围神经损害的表现,但诊断分级仍以急性期表现为依据。</sup> A.4<sup>丙烯酰胺皮肤接触如引起接触部位皮炎,可根据</sup> GBZ18<sup>、</sup> GBZ20<sup>进行诊断和处理。</sup> A.5<sup>四肢震动觉障碍及跟腱反射减弱是慢性轻度中毒的早期表现,因此,应反复仔细检查这两项体征,</sup> 检查跟腱反射应取俯卧屈膝位法。 A.6<sup>深感觉(震动觉、位置觉)障碍引起的共济失调,为感觉性共济失调,主要表现为闭目站立困难即</sup> Romberg<sup>征(</sup> +<sup>)。而小脑功能障碍所致的小脑性共济失调,睁眼闭眼对站立的稳定性影响不大,其主</sup> 要表现包括精细动作不能、步态蹒跚、眼球水平性震颤、四肢肌张力降低、指鼻及跟膝胫试验不稳、轮替 动作失调等。 

- A.7<sup>神经</sup> -<sup>肌电图检查对本病早期诊断有重要意义。慢性丙烯酰胺中毒以周围神经轴索损害为主,因</sup> 此,应重点检查四肢远端肌肉的肌电图及四肢感觉、运动神经传导速度,检查方法及其结果判断基准参 见 GBZ/T247。 

A.8<sup>以中枢神经系统功能障碍为主要表现的急性丙烯酰胺中毒需要与脑出血或脑栓塞、外伤、癫痫、急</sup> 性药物中毒、中枢感染性疾病等鉴别;以周围神经损害为主要表现的慢性丙烯酰胺中毒需要排除其他原 因引起的周围神经病,如呋喃类、异烟肼、砷、三氯乙烯、氯丙烯、磷酸三邻甲苯酯(TOCP)、甲基正丁基 酮、正已烷等中毒及糖尿病、感染性多发性神经炎等。
