# 前 言 

> <sup>根据《中华人民共和国职业病防治法》制定本标准。</sup> 本标准按照 GB/T1.1<sup>—</sup> 2009<sup>给出的规则起草。</sup> 

本标准的第6章为推荐性的,其余为强制性的。 

本标准代替 GBZ14—2002《职业性急性氨中毒诊断标准》。 与 GBZ14—2002相比主要修改如下:

# 职业性急性氨中毒的诊断 

## 1<sup>范围</sup> 

本标准规定了职业性急性氨中毒的诊断及处理原则。 

本标准适用于职业性急性氨中毒的诊断及处理。

## 3<sup>诊断原则</sup> 

根据短时间内吸入较高浓度氨气的职业史,以急性呼吸系统损害为主的临床表现和胸部 X 射线影 像学检查为主要依据,结合血气分析及现场职业卫生学调查结果,进行综合分析,排除其他病因所致类 似疾病后,方可诊断。 

## 4<sup>接触反应</sup> 

根据短时间吸入氨气的职业史,出现眼和上呼吸道刺激症状,如呛咳、流泪、流涕、咽干等,肺部无阳 性体征,胸部 X 射线检查无异常发现,48h内症状明显减轻或消失。 

## 5<sup>诊断分级</sup> 

## 5.1<sup>轻度中毒</sup> 

具有下列表现之一者: 

- a<sup>)咳嗽、咳痰、咽痛、声音嘶哑、胸闷,肺部出现干性啰音,胸部</sup> X<sup>射线检查显示肺纹理增强,符合</sup> 急性气管-支气管炎表现; 

b<sup>)一至二度喉阻塞(见</sup> GBZ73<sup>)。</sup> 

## 5.2<sup>中度中毒</sup> 

具有下列表现之一者: 

- a<sup>)剧烈咳嗽、呼吸频速、轻度发绀,肺部出现干、湿啰音;胸部</sup> X<sup>射线检查显示肺野内出现边缘模</sup> 糊伴散在斑片状渗出浸润阴影,符合支气管肺炎表现; 

- b<sup>)咳嗽、气急、呼吸困难较严重,两肺呼吸音减低,胸部</sup> X<sup>射线检查显示肺门阴影增宽、两肺散在</sup>

# 5.3<sup>重度中毒</sup> 

具有下列表现之一者: 

- a<sup>)剧烈咳嗽、咯大量粉红色泡沫痰伴明显呼吸困难、发绀,双肺广泛湿啰音,胸部</sup> X<sup>射线检查显</sup> 示两肺野有大小不等边缘模糊的斑片状或云絮状阴影,有的可融合成大片状或蝶状阴影,符合 肺泡性肺水肿表现;血气分析常呈重度低氧血症; 

- b<sup>)急性呼吸窘迫综合征(</sup> ARDS<sup>);</sup> 

c<sup>)四度喉阻塞(见</sup> GBZ73<sup>);</sup> 

d<sup>)并发较重气胸或纵隔气肿;</sup> 

- e<sup>)窒息。</sup> 

# 6<sup>处理原则</sup> 

# 6.1<sup>治疗原则</sup> 

6.1.1<sup>迅速安全将患者移至空气新鲜处,给予保温;彻底冲洗污染的眼和皮肤(见</sup> GBZ51<sup>、</sup> GBZ54<sup>)。</sup> 6.1.2<sup>保持呼吸道通畅:给予支气管解痉剂、去泡沫剂(如</sup> 10%<sup>二甲基硅油)、雾化吸入疗法;必要时给</sup> 予气管切开,尤其是支气管黏膜脱落造成严重窒息患者应立即气管切开,及时吸出脱落黏膜,防止窒息。 6.1.3<sup>防治肺水肿:可早期、足量、短程应用糖皮质激素,莨菪碱类、茶碱类、利尿剂等药物,尤应注意限</sup> 制补液量,维持水、电解质及酸碱平衡。 

6.1.4<sup>合理氧疗,必要时给予机械通气。</sup> 6.1.5<sup>积极控制感染,及时、合理应用抗生素,防治并发症。</sup> 6.1.6<sup>发生</sup> ARDS<sup>时,参照</sup> GBZ73<sup>进行。</sup> 

# 6.2<sup>其他处理</sup> 

轻度中毒治愈后可回原岗位,中、重度中毒一般应调离刺激性气体作业,如需劳动能力鉴定,可参照 GB<sup>/</sup> T16180<sup>处理。</sup>

# 正确使用本标准的说明 

A.1<sup>氨中毒以气管、支气管损害为突出表现,且病程易反复,故诊断、分级应综合分析、全面考虑。动脉</sup> 血气分析对判断病情、指导治疗有重要参考意义,应尽可能及时检测。 

A.2<sup>防治肺水肿是急性氨中毒治疗重点,同时不宜快速大量补液,以免诱发、加重肺水肿;由于氨的强</sup> 烈腐蚀性易引起气胸、纵隔气肿等,如使用机械通气正压给氧时应慎重且压力不宜过高。 

A.3<sup>防治气道堵塞:气管、支气管灼伤坏死的黏膜易在中毒后</sup> 3d~7d<sup>左右脱落,如发现气道堵塞现</sup> 象,应尽快设法应用喉镜或支气管镜取出堵塞物,必要时做气管切开。 

A.4<sup>正确认识、早期诊断氨中毒所致的</sup> ARDS<sup>是挽救患者生命,减少并发症的关键;</sup> ARDS<sup>诊断标准、</sup> 治疗原则(见 GBZ73)。 

A.5<sup>含氨化合物多为碱性液体,氨腐蚀性极强,氨中毒时常伴有眼及皮肤灼伤,故应立即彻底冲洗污染</sup> 的眼及皮肤,并请专科给以相应的治疗措施。 

A.6<sup>三凹症是指吸气时胸骨上窝、锁骨上窝、肋间隙出现明显凹陷,是由于上部气道梗阻所致吸气性呼</sup> 吸困难。
