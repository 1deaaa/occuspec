# 职业性氯丁二烯中毒的诊断

## 3<sup>诊断原则</sup> 

## 3.1<sup>急性中毒</sup> 

根据短期内接触较高浓度氯丁二烯的职业史,以中枢神经系统和(或)呼吸系统急性损害为主的临 床表现,结合实验室检查结果及工作场所职业卫生学调查资料,进行综合分析,排除其他原因所致类似 疾病后,方可诊断。 

## 3.2<sup>慢性中毒</sup> 

具有1年以上(含1年)密切接触氯丁二烯的职业史,以肝脏、神经系统损害为主的临床表现,结合实验室 检查结果及工作场所职业卫生学资料,进行综合分析,排除其他原因所致类似疾病后,方可诊断。 

## 4<sup>接触反应</sup> 

短期内接触较高浓度氯丁二烯后,出现头昏、头痛、或流泪、咽干痛、咳嗽、胸闷、气急、恶心等症状, 无阳性体征,胸部 X 射线无异常,并于脱离接触72h内症状明显减轻或消失。 

## 5<sup>诊断分级</sup> 

## 5.1<sup>急性中毒</sup> 

## 5.1.1<sup>轻度中毒</sup> 

短期内接触较高浓度氯丁二烯后,出现头晕、头痛、乏力、恶心、呕吐、胸闷、气急等症状,及眼结膜充 血、咽部充血等体征,并具备下列表现之一者: 

a<sup>)急性轻度中毒性脑病,如轻度意识障碍、步态蹒跚(见</sup> GBZ76<sup>);</sup> 

b<sup>)急性气管</sup> -<sup>支气管炎(见</sup> GBZ73<sup>)。</sup>

# 5.1.2<sup>中度中毒</sup> 

出现下列表现之一者: 

a<sup>)急性中度中毒性脑病,如中度意识障碍、共济失调等表现(见</sup> GBZ76<sup>);</sup> 

b<sup>)急性支气管肺炎或间质性肺水肿(见</sup> GBZ73<sup>)。</sup> 

# 5.1.3<sup>重度中毒</sup> 

出现下列表现之一者: 

a<sup>)急性重度中毒性脑病,如重度意识障碍(见</sup> GBZ76<sup>);</sup> 

b<sup>)肺泡性肺水肿(见</sup> GBZ73<sup>)。</sup> 

# 5.2<sup>慢性中毒</sup> 

# 5.2.1<sup>轻度中毒</sup> 

具有1年以上(含1年)氯丁二烯职业接触史,出现头晕、头痛、倦怠、乏力、失眠、易激动、记忆力减 退等临床症状,并具备下列表现之一者: 

- a<sup>)中度至重度脱发和神经衰弱综合征;</sup> 

- b<sup>)慢性轻度中毒性肝病(见</sup> GBZ59<sup>),可伴有血清蛋白电泳</sup> β<sup>球蛋白比值自身前后对比降低</sup> 20% 以上。 

# 5.2.2<sup>中度中毒</sup> 

出现慢性中度中毒性肝病(见 GBZ59)。 

5.2.3<sup>重度中毒</sup> 

出现慢性重度中毒性肝病(见 GBZ59)。 

# 6<sup>处理原则</sup> 

# 6.1<sup>治疗原则</sup> 

6.1.1<sup>急性中毒立即脱离中毒现场,清洗被污染的眼和皮肤,更换被污染衣物,保持安静、保暖、给氧。</sup> 急性期注意卧床休息,以对症及支持治疗为主,必要时给予糖皮质激素治疗。 6.1.2<sup>慢性中毒治疗期间脱离氯丁二烯作业,适当休息,加强营养,对症治疗。</sup> 

6.2<sup>其他处理</sup> 

# 6.2.1<sup>急性中毒</sup> 

轻、中度中毒经治愈后可恢复工作,重度中毒视病情脱离原岗位或从事轻工作。 

# 6.2.2<sup>慢性中毒</sup> 

轻、中度中毒者治愈后可恢复原工作。重度中毒者不再从事氯丁二烯作业,视病情休息或从事轻工 作。若需劳动能力鉴定者,按 GB/T16180处理。

# 正确使用本标准的说明 

- A.1<sup>氯丁二烯(</sup> 2-<sup>氯</sup> -1<sup>,</sup> 3-<sup>丁二烯)是生产氯丁橡胶的液态单体,能与苯乙烯、丙烯腈、异戊二烯等共聚,</sup> 生产各种合成橡胶;也是其他聚氯丁二烯产品,如氯丁胶乳及氯丁胶沥青等的单体。凡因从事生产氯丁 二烯以及各种含有氯丁二烯单体的氯丁橡胶及胶乳、黏合剂等生产和加工时,均有可能发生氯丁二烯 中毒。 

- A.2<sup>急性氯丁二烯中毒临床表现以中枢神经系统及眼和呼吸道急性损害为主。由于氯丁二烯具有麻</sup> 醉作用,吸入后可使患者迅速麻痹而陷入昏迷状态,脱离现场后大部分于5min~10min清醒。较高浓 度吸入可迅速抑制呼吸中枢,可在发病早期即出现呼吸困难或呼吸骤停。 

- A.3<sup>慢性氯丁二烯中毒首先出现神经衰弱综合征表现,继而出现肝脏损害。神经衰弱综合征为非特异</sup> 性,客观性较差,故未单独列为诊断分级指标,但由于其发生率高而作为慢性中毒诊断的前提条件。 

- A.4<sup>脱发是氯丁二烯慢性中毒的临床特点,不是所有接触者皆能发生。脱发程度分为:</sup> 

   - a<sup>)轻度用手轻抹头顶,即有较多的头发脱落;</sup> 

b<sup>)中度头发脱落至明显稀疏程度;</sup> 

c<sup>)重度头发基本脱光,可伴有眉毛、腋毛、阴毛的脱落。</sup> 

脱离接触后可逐渐自行恢复。 

- A.5<sup>指甲变色常在接触氯丁二烯</sup> 15d~30d<sup>出现。从指甲根部起始出现紫褐色,常先累及双侧或一</sup> 侧的拇指指甲。脱离作业3周后,色斑变淡,随指甲生长,紫褐色向远端推进,甲根部又出现正常的指甲 色。若再接触则指甲变色,又可反复,故指甲变色可作为接触氯丁二烯的佐证。 

- A.6<sup>血清蛋白电泳</sup> β<sup>球蛋白比值降低属氯丁二烯中毒性肝病的特征之一。</sup> β<sup>球蛋白比值自身前后对</sup> 比降低20%以上为判定中毒诊断界限值。自身对比方法有: 

a<sup>)接触氯丁二烯作业前后</sup> β<sup>球蛋白比值自身对比;</sup> 

   - b<sup>)脱离接触氯丁二烯作业治疗</sup> 1~2<sup>个月后,</sup> β<sup>球蛋白比值自身对比。脱离氯丁二烯接触后</sup> β<sup>球</sup> 蛋白比值可恢复正常,重新接触又迅速下降。 

- A.7<sup>氯丁二烯中毒性肝病与其他慢性肝病的临床表现不完全相同。首先,前者发病初期消化道症状可</sup> 不明显,且常伴有神经衰弱综合征及发生不同程度脱发及指甲变色等特点;而其他肝病发病早期消化道 症状及肝功能异常明显。其二,血清蛋白电泳检测结果不一致,前者表现为白蛋白比值升高,β球蛋白 比值降低,α和 γ球蛋白无显著改变;其他肝病则相反,其血清蛋白电泳表现为白蛋白比值下降、白球比 例(A/G)降低或倒置,γ球蛋白比值增高。
